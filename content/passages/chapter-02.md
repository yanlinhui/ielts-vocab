# 园子里的学问

我退休那年把阳台收拾出来，种了第一盆 {{herb}}——薄荷，后来又添了几样香草。

「你别小看它，」我跟孙子说，「一片叶子底下全是活儿。」叶子把 {{sunlight}} 收进去，拿 {{dioxide}} 和水做原料做出糖，再吐出氧气——这就是 {{photosynthesis}}。晚上没有光，它反过来 {{respire}}，跟人一样。

我书架上那本《植物学入门》是我父亲留下的，封面上写着 {{botany}}。我不认得拉丁名，但我记得住那些词：一株活的东西叫 {{organism}}；它怎么长成它父母的样子，是 {{genetics}} 的事。偶尔冒出一个没见过的样子，那叫 {{mutation}}。同一个种里长得不一样，叫 {{variation}}；一园子的东西各不相同，叫 {{diversity}}。要是把两个不一样的凑到一起，那就是 {{hybridisation}}。

「{{classify}} 是个苦活。」我说，「你得盯着看，看它怎么 {{reproduce}}，怎么一代一代 {{evolve}}。」

我种过一株 {{perennial}} 的鸢尾，年年开。我说那东西的性子 {{fluctuate}} 得厉害，去年开了七朵，今年两朵。院里那片 {{vegetation}} 也一样，孙子放假回来总说「好像又不一样了」。

我喜欢那些不起眼的。墙角那片 {{fungus}} 是我特意留的，一有雨就冒出来；面包上的 {{mould}} 我也舍不得扔，留着看。春天风一起来，空气里全是 {{pollen}}，孙子就打喷嚏。

「没有花粉，就结不了果。」

{{seed}} 埋下去，先是 {{germinate}}，顶出一点白；然后 {{burgeon}}，抽芽；再往后是 {{flower}}、{{blossom}}、{{bloom}}——我坚持说这三个词不一样：一个说的是开花这件事，一个说的是花开满了的样子，一个说的是开得好。院里那股 {{scent}} 是茉莉，我管它叫 {{aromatic}}，说这个词念出来就像闻到了。

{{fruit}} 一天天 {{ripen}}，摘下来分给邻居。之后叶子就该 {{wither}} 了。掉在地上的叶子和果皮慢慢 {{decompose}}，先是 {{rot}}，再是 {{decay}}。我从来不扫干净，说那是给明年的肥。只有一样东西我看不惯——冰箱里放久了那股 {{stale}} 味。我说那跟园子里的腐烂不是一回事：园子里是活着在变，那是死了还在。

我还种过一盆奇怪的菊花。标签上写着 {{short-day}}，后来翻书才知道那是「短日照」的意思：白天够短才开。旁边那盆写着 {{shade-tolerant}}，耐阴。我笑说这两个词听着像给人写的。

「{{horticulture}} 这个词，」我跟孙子说，「听着高级，其实就是伺候它们。」

孙子问：「那 {{ecology}} 呢？」

「那是问它们跟谁住在一起。」我指着整个阳台，「这一阳台，加上土、水、虫子，就是一个 {{ecosystem}}。」

「那 {{eco-friendly}} 是什么意思？」

「就是别把它们弄坏。」

# 种地

老陈家的地在村北，是全村最好的一片 {{arable}} 田。

「这块地是我爷爷开的。」老陈说，「那时候全是荒坡，他一锄一锄 {{reclaim}} 出来的。」

他有一把 {{plough}}、一把 {{spade}}、一把 {{rake}}。春天的活是 {{cultivate}}——翻地、下种、浇水。

「你不要小看这把 {{spade}}，」他说，「它比我年轻时候轻了，是我老了。」

夏天最难。草长得比苗快，老陈连着几天在地里 {{weed}}。有一种草带 {{thorn}}，一天下来手上全是口子。他还得盯着 {{reed}}——河边那些芦苇，一年不割就爬进田里。

到了秋天是 {{harvest}}。他不说「收割」，他说 {{pick}}，说 {{pluck}}——摘豆角是 pick，掰玉米是 pluck，他说这俩感觉不一样，一个是拧下来，一个是掰断。老陈把 {{yield}} 算给儿子听：一亩地能出多少斤。

{{hay}} 晒在院子里，{{stack}} 成一垛；割下来的枝条 {{bundle}} 成捆，{{bunch}} 是更小的一把，是他老婆扎来插 {{vase}} 的。柴火 {{heap}} 在墙角，他说看着就踏实。

儿子不种地，在城里的 {{field}} 干别的——「领域」这个词老陈说他不认，他只知道地。儿子劝他把地包出去，他不肯。

村后那片坡他年轻时种过树。现在是 {{plantation}}，一整片 {{pine}}，山脚下还有 {{vine}}。坡上修了 {{terrace}}，一层一层，像台阶。再往上就是没人管的 {{jungle}}，天热得钻不进去；翻过山头是 {{rainforest}}，一年到头是绿的。

「树是有数的。」老陈指了指山上，「{{timber}}、{{charcoal}}、{{log}}，都是它身上下来的。现在有人专门管这个，叫 {{forestry}}。」

他自己会看树：{{trunk}} 是身子，{{branch}} 是枝，{{bough}} 是粗枝。{{root}} 在地下，他说那是最要紧的一部分——「你看不见它，可它撑着整棵树。」

他老婆在屋后种了几样花：{{violet}}、{{tulip}}，还有一丛 {{mint}}。屋前那片 {{lawn}} 是儿子的主意，说好看；老陈嫌它没用，不如种 {{grass}} 养牛。只有屋后那片 {{meadow}} 他留着，说那才是地本来的样子。

老陈退休那年把牛卖了。地里的活现在是他自己干，慢慢干。

「你问我一年剩多少？」他笑，「{{rear}} 两头牛，收点粮，够吃。」

「那地呢？」

「地在。」老陈说，「这就够了。」

# 潮水线

林晚照在海边做野外记录，已经第六年。

每天早上她沿着 {{reef}} 走过去。礁石上那层绿是 {{alga}}，看着不起眼，可她手里那本册子有半本记的是它——潮水线上下的东西，全靠它养。

本子上写过一句：{{enzyme}} 和 {{catalyst}} 是同一类东西的两个名字，都是让事情发生得快一点，而自己不变。林晚照觉得自己干这个也差不多。

海边的林子和山上不一样。叶子把光收进来，再把 {{nutrient}} 送下去；落在地上的东西慢慢烂，把养分还回去。整条链子说是靠 {{energy}} 在走——她不同意，她说那是靠时间在走。

她量过很多东西：一株树一天 {{absorb}} 多少水，一年往下 {{release}} 多少；林子里的空气 {{circulation}} 跟外面差多少；那片林子的 {{uptake}} 有时候会 {{exceed}} 她的估算；一年的 {{emission}} 她也记。林子周围的 {{surroundings}} 是另一本册子，两本她一起看。

「你别把林子当成一堆树，」林晚照跟实习生说，「它是一套 {{mechanism}}。一棵死了，另一棵补上来；这边水多了，那边就干。它自己有个 {{counterbalance}}。」

实习生问她为什么不做实验室的活。林晚照说实验里的 {{experimental}} 条件是干净的，可林子不干净——旱季里最先 {{perish}} 的就是那些根扎得浅的苗，没有哪本书会告诉你哪一株会死。

她这些年见过两种结果。一种是 {{favourable}} 的：封了山，十年之后林子自己长回来，{{productive}} 得超出预期，{{effective}} 得不用人管。另一种是一场 {{bush fire}} 来了，是从山下起的，那年春天 {{seasonal}} 的干旱比往年厉害。她看着半座山烧了三天，最后是雨把它 {{extinguish}} 掉的。

「那之后我才知道，」林晚照说，「有些东西可以 {{destruct}}，可以 {{ruin}}，可以 {{demolish}}——你可以把它拆掉。但有些东西是一去就没了，那叫 {{extinction}}。前三个是『坏了』，后一个是『没有了』。」

那次之后她写过一份报告，讲修路、砍树、引水怎么一点点 {{undermine}} 那片林子，怎么 {{infringe}} 到最后一个洼地。报告里她用了 {{massive}} 和 {{immense}} 两个词——「这不是一块地的事，这是一整片。」{{considerable}} 是最轻的说法，她后来说她不该用。

林晚照的报告没什么人看。可那年之后，那片洼地留下来了。

「{{protect}} 和 {{preserve}} 是两件事。」她说，「一个是不让动，一个是让它在。我干的是后一件。」

「{{conservation}} 呢？」

「那是别人给我这个活起的名字。」

她本子最后一页抄了一行字：每一个 {{pattern}} 都会有个 {{outcome}}，每一件小东西都会有 {{impact}}。这三句她写的时候用的是铅笔，说铅笔好改。

林晚照从来不追求 {{maximal}}——她说那是贪心。她也不肯降到 {{minimal}}，那叫应付。她要的是 {{optimal}}：够用的 {{optimal}} 就好。
